
# Calculadora MVC

Calculadora desenvolvida com HTML, CSS e JavaScript, utilizando o padrão arquitetural MVC (Model-View-Controller).

## Resumo

Projeto acadêmico desenvolvido em dupla com o objetivo de praticar o desenvolvimento web e a organização de código utilizando o padrão MVC.

## Funcionalidades

- Operações matemáticas básicas
- Adição, subtração, multiplicação e divisão
- Números decimais
- Exibição da operação no histórico
- Tratamento de divisão por zero
- Botão para limpar os valores
- Interface responsiva para diferentes tamanhos de tela

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura dos arquivos

```text
calculadora-mvc/
├── index.html
├── style.css
├── model.js
├── view.js
├── controller.js
├── app.js
└── README.md
```

## Instalação

1. Clone o repositório ou baixe os arquivos.
2. Mantenha todos os arquivos na mesma pasta.
3. Abra o arquivo `index.html` em um navegador.

## Uso

Clique nos números e operadores para realizar cálculos. Utilize o botão `=` para visualizar o resultado e `AC` para limpar a calculadora.

## Objetivo acadêmico

Praticar conceitos de desenvolvimento web, manipulação do DOM e separação de responsabilidades com o padrão MVC.
